# Customer purchase journeys

Planning references only; not Retell workflow definitions. Licensing requirements use separate reviewed Phase B rules.

## Adult first-time applicant

Caller need → Adult 6 Hours Online Permit Class → 6-Hour Online Permit Class → package preference → school prerequisites and separately verified licensing pathway → purchase/enrollment and confirmed online access; timed live slot not established as necessary.

## Adult driving lesson customer

Caller need → Adult Driving Lessons in Plano → 2 hours, 4 hours, 6 hours, 8 hours, 10 hours → package preference → school prerequisites and separately verified licensing pathway → booking required at scheduling stage → authorized live availability → caller-selected returned slot(s) → confirmed backend booking result.

## Teen full driver-ed customer

Caller need → Teen Driver Education → 24 Hr Classroom + Driving Package → package preference → school prerequisites and separately verified licensing pathway → booking required at scheduling stage → authorized live availability → caller-selected returned slot(s) → confirmed backend booking result.

## Teen behind-the-wheel customer

Caller need → Teen Driver Education → Behind the Wheel Only (7 & 7) → package preference → school prerequisites and separately verified licensing pathway → booking required at scheduling stage → authorized live availability → caller-selected returned slot(s) → confirmed backend booking result.

## Parent-taught customer

Caller need → Parent-Taught Log Driving Hours → 10 hours, 15 hours, 30 hours → package preference → school prerequisites and separately verified licensing pathway → booking required at scheduling stage → authorized live availability → caller-selected returned slot(s) → confirmed backend booking result.

## Road-test-only customer

Caller need → 3rd Party Road Test in Plano → Road test only → package preference → school prerequisites and separately verified licensing pathway → booking required at scheduling stage → authorized live availability → caller-selected returned slot(s) → confirmed backend booking result.

## Road-test + preparation customer

Caller need → 3rd Party Road Test in Plano → Practice session + road test → package preference → school prerequisites and separately verified licensing pathway → booking required at scheduling stage → authorized live availability → caller-selected returned slot(s) → confirmed backend booking result.

An adult first-time caller aged 25+ must not be forced into education; optional driving lessons and licensing guidance are separate choices. A sales selection is not proof of readiness, payment, availability or a completed booking.
